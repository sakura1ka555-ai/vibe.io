# VIBE 🎬💜

VIBE — Telegram Mini App для совместного просмотра фильмов и видео с друзьями в реальном времени.

## Идея

- Создание комнат просмотра
- Приглашение друзей через Telegram
- Синхронный просмотр видео
- Чат и реакции
- Совместные вечера на расстоянии

## Технологии

Frontend:
- React
- TypeScript
- Telegram Mini Apps SDK

Backend:
- Node.js
- WebSocket
- PostgreSQL
- Redis
